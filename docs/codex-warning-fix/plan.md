# Codex 시작 경고 수정 계획

목표. 지원하지 않는 훅 설정 4개와 스킬 목록 용량 초과 경고를 기존 기능 손실 없이 제거한다.

1. CLI·데스크톱 버전과 실제 설정·공식 구현을 확인한다.
2. config.toml·구형 CLI를 백업하고 CLI를 공식 최신 안정판으로 업데이트한다. 승인된 훅 콘텐츠 해시를 보존한다. 예산 설정이 효과가 없으면 사용자 선택에 따라 스킬 활성 범위를 선별한다.
3. 두 실행 파일의 실제 설정 로딩과 프롬프트 렌더링으로 경고 제거를 검증한다.

범위. 사용자 Codex config.toml·독립 설치 CLI와 이 작업의 기록만 변경한다. 스킬 원본과 플러그인을 삭제하지 않으며 훅 신뢰 우회와 Isaac Sim 소스 변경은 하지 않는다.

완료 기준. TOML 파싱 성공, 기존 설정 보존 확인, 신규 설정 경고 없음, 스킬 목록 누락 경고 없음. 현재 세션은 재시작 전 상태임을 구분한다.
